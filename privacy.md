# FamilyFinance — политика конфиденциальности

*Действует с 21.09.2026.*

FamilyFinance — приложение для учёта расходов одной семьи. Оно не распространяется публично и не имеет своего сервера.

## Какие данные обрабатываются

- **Операции** (дата, сумма, категория, комментарий) и настройки хранятся только на телефоне пользователя.
- **Google-таблица бюджета**, которую пользователь сам подключил: приложение читает колонку A (категории), строку 2 (месяцы) и ячейки [категория × месяц] и записывает в эти ячейки месячные суммы. Доступ — область `https://www.googleapis.com/auth/spreadsheets`.
- **Google Диск**: приложение создаёт папку `familyfinance` и сохраняет в неё резервные копии своих данных. Доступ — область `https://www.googleapis.com/auth/drive.file`: приложение видит только файлы, которые создало само.
- **Адрес электронной почты аккаунта Google** — чтобы показать пользователю, каким аккаунтом выполнен вход.

## Чего приложение не делает

- Не передаёт данные никому, кроме Google (Таблицы и Диск пользователя) по действию или настройке пользователя.
- Не использует рекламу, аналитику, трекеры и сторонние SDK сбора данных.
- Не читает другие таблицы и файлы пользователя, кроме подключённой таблицы и своих файлов на Диске.

Использование данных, полученных через API Google, соответствует [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use.

## Хранение и удаление

- Данные на телефоне удаляются вместе с приложением или через *Настройки Android → Приложения → Семейный бюджет → Хранилище → Очистить данные*.
- Резервные копии на Google Диске удаляются пользователем в папке `familyfinance`.
- Доступ приложения к аккаунту Google отзывается в приложении (*Настройки → Аккаунт и таблица → Выйти*) или на странице [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
